            Settings

            A Gemini key is optional. Without one, everything still works: the local generator writes the drafts and the sample repo's pre-made outputs are shown. With a key, the “Polish with Gemini” buttons rewrite each artefact with the model, using only the extracted facts.

            The key is saved in localStorage on this device only. It is sent to Google's API when you press a Polish button, and nowhere else. No key is ever stored in a run or sent to any other service.
